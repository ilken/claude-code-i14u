# Web UI Design

For any UI task:

1. **Always read `frontend-design.md`** — design philosophy and quality bar.
2. **Check the project root** for `BRAND-VOICE.md`, `DESIGN-TOKENS.md`, and `MOTION-SPEC.md`. If they exist, they override the generic approach — follow them exactly.
3. **When structuring components**, read `web-component-patterns.md` — component size limits, hooks for logic, constants files.
4. **For design-system research** (palettes, typography, styles, charts), use the `ui-ux-pro-max` skill and its search script.

## New projects

Copy the three templates from `templates/` (`BRAND-VOICE.md`, `DESIGN-TOKENS.md`, `MOTION-SPEC.md`) to the project root and fill them in for the project's brand before building any UI.
